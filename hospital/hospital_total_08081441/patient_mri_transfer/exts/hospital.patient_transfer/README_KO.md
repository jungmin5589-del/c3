# Dual Patient MRI Transfer Runtime

이 폴더는 김서울·박인천 침대 위에 누운 환자 모델 두 명을 배치하고, 실제 선택한 MRI 환자 테이블과 운반 침대 사이를 반복 이동시키는 Isaac Sim 확장입니다.

- 김서울: Laying Breathless
- 박인천: Laying Sleeping
- 진입 1.25 m / 이탈 1.75 m / 유지 1.0초
- MRI 1인 점유 보호
- K: Stage에서 선택한 실제 MRI 테이블 저장
- L: 상태 출력

전체 실행법은 프로젝트 루트의 `PATIENT_MRI_START_KO.md`를 참조하세요.
