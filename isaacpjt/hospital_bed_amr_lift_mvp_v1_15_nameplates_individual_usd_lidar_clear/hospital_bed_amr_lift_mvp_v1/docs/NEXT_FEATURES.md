# 다음 개발 기능 우선순위

## 1. SLAM·Nav2 완성

- AMR별 `scan`, `odom`, TF를 이용한 SLAM Toolbox
- 저장 맵 기반 AMCL Localization
- Nav2 Goal Pose 자율주행
- 옴니 AMR에 맞는 holonomic local planner 설정

## 2. 안전 계층

- 전방·측방 감속 영역
- 급정지 영역
- 침대 적재 시 속도 자동 제한
- 사람 또는 장애물 접근 시 정지
- 통신 명령 timeout 시 자동 정지

## 3. 병원용 Fleet Manager

- AMR 상태: 대기, 이동, 도킹, 적재, 운반, 오류
- 침대 점유 상태와 AMR-침대 할당
- 복도 교차로·문·엘리베이터 자원 예약
- 두 AMR 경로 충돌 방지

## 4. 정밀 도킹

- AprilTag 또는 ArUco 기반 침대 후면 pose 인식
- LiDAR 선분/다리 검출 기반 최종 정렬
- 결합 성공 센서와 실패 재시도
- 리프트 하중 또는 접촉 센서

## 5. 병원 이송 시나리오

- 병실 → MRI
- 응급실 → 수술실
- 목적지 도착 후 자동 분리
- 간호사 승인·취소·긴급정지 UI
- 환자 탑승 상태에서 더 낮은 가속도·회전속도 적용

## 6. 배터리와 충전

- 배터리 SOC 토픽
- 임계치 이하 자동 충전 복귀
- 충전 Docking Server 연동
- 임무 수행 가능 여부 판단

## 7. 기록과 재현

- rosbag2 센서·명령·TF 기록
- 임무 ID, 침대 ID, 출발·도착 시간 저장
- 오류 원인과 복구 횟수 저장
- 반복 가능한 자동 테스트 시나리오
