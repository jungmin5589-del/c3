# 듀얼 키보드 조작 — v1.12

## AMR1

```text
W / S       전진 / 후진
A / D       좌회전 / 우회전
Q / E       왼쪽 / 오른쪽 옴니 횡이동
R / V       리프트 상승 / 하강
Left Shift 자기 결합 ON/OFF
Space       비상 정지
```

## AMR2

```text
↑ / ↓       전진 / 후진
← / →       좌회전 / 우회전
/ + ,       왼쪽 옴니 횡이동
/ + .       오른쪽 옴니 횡이동
[ / ]       리프트 상승 / 하강
Right Shift 자기 결합 ON/OFF
Enter       비상 정지
```

`/ + ,`는 `/` 키를 누른 상태에서 `,`를 누르는 조합이다. `Right Ctrl`은 더 이상 사용하지 않는다.

대각선 이동:

```text
↑ + / + ,   전진하면서 왼쪽 횡이동
↑ + / + .   전진하면서 오른쪽 횡이동
↓ + / + ,   후진하면서 왼쪽 횡이동
↓ + / + .   후진하면서 오른쪽 횡이동
```
